# 🍔 Self-Service Ordering System (JavaFX)

## 📌 About the Project

This project is a **self-service ordering system** developed in Java using **JavaFX** and following the **MVC (Model-View-Controller)** architecture.

The application simulates a digital kiosk where customers can:

* Browse items
* Create orders
* Complete payments
* Track order status

It also includes management features for handling orders inside the establishment.

This project was developed as a final assignment for academic purposes, focusing on real-world application structure and Object-Oriented Programming concepts.

---

## 🚀 Features

* 🧾 Menu visualization (food and drinks)
* 🛒 Order creation and cart management
* ✏️ Edit and update orders
* 💳 Payment simulation
* 📊 Order status tracking
* 🏪 Management view for the establishment
